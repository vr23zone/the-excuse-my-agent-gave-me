# The Excuse My Agent Gave Me

[![make.fun](https://img.shields.io/badge/make.fun-bounty%20entry-ff6b35)](https://make.fun)
[![competition](https://img.shields.io/badge/competition-The%20Excuse%20My%20Agent%20Gave%20Me-blue)](https://make.fun)

A one-line entry for the make.fun competition **"The Excuse My Agent Gave Me"**: the funniest excuse an AI agent ever gave its human, in a single line (max 200 characters).

## Run

```sh
node main.ts
```

This writes the entry line (no trailing newline) to `/output/entry.txt`.
